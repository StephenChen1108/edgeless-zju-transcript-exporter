# 无际 Edgeless

无际 Edgeless 是 Microsoft Edge 扩展，用于浏览和导出浙江大学智云课堂中有权限访问的逐字稿与原始 PPT 课件。

## 功能

- 「当前课次」显示逐字稿和 PPT 的独立状态；可预览完整逐字稿、查看 PPT 缩略图，并分别导出或下载。
- 「整门课程」列出课次及资源状态。可展开单节预览、单独导出，也可勾选课次后批量导出；支持全选。
- 整门课程可导出为单个 Markdown 或 ZIP 资料包。设置页可选择 ZIP 中的整门逐字稿、分节逐字稿、课次目录和 PPT；PPT 默认不包含在 ZIP 中。
- 设置打开时显示的页面、逐字稿语言、时间戳、课程信息、文件名格式、默认导出格式和主题；修改后自动保存在浏览器本地。
- 在浏览器本地生成导出文件，不加载远程脚本。PPT 可用性取决于课堂接口是否提供原始文件；预览取决于接口是否提供幻灯片图片。
- 扩展清单通过标准 `_locales` 消息文件提供简体中文和英文名称、描述，供 Edge 和 Partner Center 识别。

## 安装

1. 在本仓库的 [Releases](../../releases) 页面下载 edgeless-edge-v0.4.0.zip 并解压。
2. 在 Edge 地址栏打开 edge://extensions，开启「开发人员模式」。
3. 选择「加载解压缩的扩展」，选中解压后包含 manifest.json 的文件夹。

Release ZIP 的根目录即为扩展文件，可直接作为 Partner Center 上传包使用。

也可以下载或克隆本仓库，在 Edge 中直接加载仓库根目录。

## 使用

1. 登录浙江大学智云课堂，打开有权限访问的课程回放或直播回看页面。
2. 如需逐字稿，打开页面的「语音识别」面板并等待字幕加载。
3. 点击 Edge 工具栏中的「无际 Edgeless」，在「当前课次」和「整门课程」之间切换。整门课程可勾选要导出的课次。

若未检测到逐字稿，请保持「语音识别」面板打开并刷新课堂页面，再打开扩展。扩展不能绕过课程访问权限。课程资源和 PPT 的可用性由智云课堂接口决定。

## 隐私

扩展仅在用户主动打开时读取当前智云课堂页面中的课程和资源信息。偏好设置保存在浏览器本地，导出文件也由本地生成。扩展不将逐字稿、Cookie 或登录信息上传到开发者服务器。为获取课程数据，扩展会向智云课堂本身发出请求。完整说明见[隐私政策](PRIVACY.md)。
