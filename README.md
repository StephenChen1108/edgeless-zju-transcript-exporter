# 无际 Edgeless

无际 Edgeless 是 Microsoft Edge 扩展，可将浙江大学智云课堂中当前课次或整门课程已有的语音识别逐字稿导出为 Markdown，也可将整门课程打包为 ZIP。

## 功能

- 导出当前课次逐字稿，保留原文、字幕顺序和时间戳。
- 汇总整门课程已有逐字稿，可导出单个 Markdown 或课程 ZIP。
- 选择导出语言、时间戳、元数据、文件名、ZIP 内容和主题；设置保存在浏览器本地。
- 可选导出接口明确提供的原始 PPT/PPTX 文件。此选项默认关闭；接口只提供幻灯片图片时不会导出图片。
- 在浏览器本地生成文件，不加载远程脚本。

## 安装

### 从 GitHub Release 安装

1. 在本仓库的 [Releases](../../releases) 页面下载 `edgeless-edge-v0.3.1.zip` 并解压。
2. 在 Edge 地址栏打开 `edge://extensions`，开启「开发人员模式」。
3. 选择「加载解压缩的扩展」，然后选择解压出的文件夹（其中应有 `manifest.json`）。

### 从源码安装

下载或克隆本仓库，在 Edge 的 `edge://extensions` 页面开启「开发人员模式」，选择「加载解压缩的扩展」，并选中本仓库目录。

## 使用

1. 登录浙江大学智云课堂，打开有权限访问的课程回放。
2. 打开页面的「语音识别」面板并等待字幕加载。
3. 点击 Edge 工具栏中的「无际 Edgeless」，选择当前课次或整门课程并导出。

若当前课次未检测到逐字稿，请保持「语音识别」面板打开并刷新回放页，再打开扩展。整门课程导出需要从回放页或已加载请求中取得课程标识。插件不能绕过课程访问权限。

## 隐私

扩展仅在用户主动打开时读取当前智云课堂页面中的课程和逐字稿信息。偏好设置保存在浏览器本地，导出文件也由本地生成。扩展不将逐字稿、Cookie 或登录信息上传到开发者服务器。为获取课程数据，扩展会向智云课堂本身发出请求。

完整说明见[隐私政策](PRIVACY.md)。
